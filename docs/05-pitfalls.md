# 踩坑清单

按环境、取景、替换、守卫四类整理。每条都是实测踩过之后写下来的。

---

## 环境

1. **PowerShell 5.1 读 UTF-8 无 BOM 的 `.ps1` 会解析错乱**：中文字符串里的引号会被误判，报"字符串缺少终止符"。脚本一律存成 **UTF-8 with BOM**，或统一用 PowerShell 7 运行。
2. `reg.exe`、`ie4uinit.exe` 不在 PATH，必须写全路径：
   - `"$env:SystemRoot\System32\reg.exe"`
   - `"$env:SystemRoot\System32\ie4uinit.exe"`
3. 内联 `python -c "..."` 传含大括号/引号/反斜杠的补丁，容易被 shell 截断。把补丁写成完整 `.py` 再执行。
4. 系统没有 ImageMagick/ffmpeg 也能做完整流程：`pillow` + 手写 ico 头（`struct`）即可。
5. 高 DPI 屏幕下 `GetWindowRect` 返回的是虚拟化坐标。要做像素级判断，先用 `SetProcessDpiAwareness(2)` 再取窗口矩形，否则数值会只有实际的一半。
6. 全屏截图 PNG 可能超过 5 MB，直接读图会失败。先按区域裁切再读。

---

## 取景与生成

7. **不要用肤色掩膜自动找脸**：不同画风、不同发色、半透明背景都会失效，连续失败多次。老实做 16 px 对照图，目视微调。
8. 「标签白像素行」自动定位桌面列也不可靠：相邻图标的标签会连成一团。
9. 16 px 的取景别按"脸在画面上三分之一"估算，会整体偏移。以实际 16 px 输出为准，迭代 2–4 轮。
10. 局部编辑类提示词只写"要改什么"，不重复描述原图已有特征，否则模型会把原图重画一遍。
11. 主体偏下的构图会在标签栏压盖后变成"半张脸"，出图阶段就要把人物往上推。

## 替换

12. 系统图标改完**必须重启 explorer**；`ie4uinit -show` 对它无效。
13. 注册表覆盖键 HKLM + HKCU 双写；只写一处有概率不生效。
14. `HKLM\SOFTWARE\Classes\CLSID\{…}\DefaultIcon` 归 TrustedInstaller 所有，管理员也写不进；不要夺取所有权，改用 `Explorer\CLSID` 覆盖键。
15. 桌面「控制面板」的真实 CLSID 是 `{5399E694-6CE5-4D6C-8FCE-1D8870FDCBA0}`；只改 `{21EC2020…}`/`{26EE0668…}` 不会变。
16. 改 `.lnk` 前先记 `target / arguments / workingDirectory / iconLocation`，回滚才有依据。
17. 快捷方式的"工作目录"经常被忽略：程序若按相对路径读资源，工作目录错就直接起不来。

---

## 守卫

18. 不要把 `.lnk` 设成只读或拒绝写入来"防重写"：软件升级需要更新目标路径，锁死后快捷方式会指向不存在的旧 exe。
19. 不要替换 exe 内嵌图标：更新即失效，还会破坏数字签名。
20. 守卫恢复后若桌面没变化，是 Explorer 图标缓存，不是失败；`SHChangeNotify` + `ie4uinit -show`，必要时重启 explorer。
21. 计划任务里别用 `pwsh` 这类可能只在开发环境 PATH 中的解释器；写绝对路径，或按 `pwsh 7 → powershell.exe` 顺序回退。
22. 计划任务的"运行超过 3 天后停止"默认是开启的，常驻脚本要显式设 `ExecutionTimeLimit = 0`。
23. 任务状态长期显示"正在运行"是正常的（常驻进程）；`LastTaskResult = 0x41301` 也是"运行中"，不要误判为失败。
24. 守卫以最高权限运行更稳（应对管理员权限的客户端），但脚本应放在非用户可写目录，避免被替换后随登录提权。
