# 图标视觉规格

所有图标共用一套几何与排版参数，改规格前先读完这一页。

---

## 1. 画布与遮罩

| 参数 | 值 |
|---|---|
| 画布 | 1024 × 1024（最终 ico 的 256 帧由它缩出） |
| 遮罩形状 | 圆角矩形（默认）；可选超椭圆（Lamé 曲线） |
| 圆角半径 | 23%（相对画布宽） |
| 超椭圆指数 n | 5（仅 `--shape superellipse` 生效） |
| 抗锯齿 | 4× 超采样后缩回（mask 在 4096 上绘制再 LANCZOS） |
| 四角 | alpha = 0（完全透明） |

`23% / n=5` 是「比普通圆角更饱满、又不至于变成胶囊」的平衡点，与 Windows 11 图标观感接近。两种形状视觉差异极小，默认用圆角矩形；需要更连续的转角曲率时再切超椭圆。

---

## 2. 标签栏

| 参数 | 值 |
|---|---|
| 位置 | 贴底，全宽通栏 |
| 高度 | `104 / 1024 = 10.16%` |
| 填充 | `rgba(12,12,16,178)` |
| 圆角 | 跟随遮罩裁切，不单独圆角 |
| 描边 | 无 |

标签栏只在底部，不遮两侧；人物主体不要压到这条带里。

---

## 3. 文字

| 参数 | 值 |
|---|---|
| 字体 | 微软雅黑 Bold（`msyhbd.ttc`）；非 Windows 环境退化为 DejaVu Sans Bold |
| 颜色 | 白 `#FFFFFF` |
| 位置 | 栏内水平居中、垂直居中 |
| 最大宽度 | 700 px |
| 最大高度 | 栏高 − 20 px |
| 自动缩放 | 从栏高起逐级缩小，直到同时满足上面两个约束 |
| 语言 | 与桌面显示名一致；中文用中文，拉丁名用拉丁 |

实测：6 个汉字会停在约 86 px；短拉丁名可到 100 px 以上。名称过长优先缩写（`Photoshop → PS`），**不要为了塞字把字压到看不清**。

---

## 4. 六尺寸与降级

| 尺寸 | 处理 |
|---|---|
| 1024 | 母版：完整底栏 + 文字 |
| 256 / 128 | 底栏 + 文字 |
| 64 / 48 / 32 | 只保留底栏，**不画字**（此尺寸下文字只会糊成灰块） |
| 16 | 纯头像：不加底栏；对比 1.15×、锐化 1.35× |

ico 文件按 `256, 128, 64, 48, 32, 16` 六帧写入，每帧 PNG 压缩；256 帧的宽高字段按 ICO 约定写 0。

体积参考：单 ico 约 130–210 KB。

---

## 5. 取景（决定 16 px 好不好认）

16 px 只有 256 个像素，能承载的信息只有「发色块 + 脸部明暗 + 一个饰物色点」。

- 主图（1024/256/128）默认用整张原图，只按画布居中裁方，不再额外放大
- 16 px 单独取一次景：正方形边长 = 原图短边 × `face-crop`（常用 0.32–0.40）
- 16 px 取景中心由 `head-x / head-y` 控制，取「双眼连线中点」最稳
- 16 px 下脸部应占约 40–55% 宽度；太小认不出，太大没有发型轮廓

调参方法：把 16 px 放大到 250 px、画十字中线，目视判断偏移方向，再改参数。改 `head-y` 影响上下，改 `head-x` 影响左右；个别图会有轻微反向，以实际输出为准。

---

## 6. 配色原则

1. 一个图标只服务一个应用，主色不超过 3 个。
2. 同厂/同类软件成组：同色相、同版式，用「饰物 + 明度」区分。
3. 背景明度要能衬出人物：浅发用中深底，深发用浅底。
4. 避免纯黑纯白大面积：缩到 32 px 会丢轮廓。

---

## 7. 命名规范

```
<应用>/
  源图_生成.png            1024 或更大母图
  <应用>_无底栏_1024.png    纯人物版（可选）
  <应用>_1024.png          带底栏母版
  <应用>_{256,128,64,48,32,16}.png
  <应用>.ico
```

多状态图标（如回收站空/满）：`<应用>_<状态>.ico`。
