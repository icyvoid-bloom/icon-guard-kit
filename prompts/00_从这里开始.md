# 傻瓜式流程：从一句话到桌面新图标

零基础照做即可。全程只有 4 个动作：**填提示词 → 出图 → 生成 ico → 换图标**。

---

## 准备（只做一次）

1. 装 Python 3.9+（安装时勾选 *Add Python to PATH*）。
2. 打开 PowerShell，执行：

```powershell
pip install pillow numpy
```

3. 记住本仓库有两个入口：
   - 生成 ico：`tools\make_icon.ps1`
   - 图形化偷懒：双击根目录 `一键生成图标.bat`（把图片拖进窗口即可）

---

## 第 1 步：填提示词（2 分钟）

打开 `prompts\03_提示词模板.txt`，只改 4 个地方：

| 占位符 | 填什么 | 例子 |
|---|---|---|
| `{{APP_NAME}}` | 软件中文名 | 代码编辑器 |
| `{{BRAND_COLOR}}` | 2–3 个品牌色 | 青蓝 + 墨绿 + 白 |
| `{{CHARACTER}}` | 一句话人设 | 银灰短发、细框眼镜、白衬衫外搭深色马甲 |
| `{{PROP}}` | 1–2 件识别物 | 发光的代码窗口、机械键盘 |

不会写人设就抄 `prompts\02_示例提示词.md` 里最像的一条，改名字和颜色即可。

---

## 第 2 步：出图（3 分钟）

把填好的提示词整段贴进生图工具，要求 **1:1 方图、1024 以上**。一次出 3 张，挑一张：

- 头肩在上半部分，眼睛清楚、不被刘海或手挡住；
- 底部 15% 没有重要内容（会被深色底栏压住）；
- 背景干净，没有文字、logo、水印、UI 截图；
- 没有多余手指、没有第二个角色。

不满意就加 `prompts\01_主提示词.md` 里的负面词重生成，**不要**拿一张构图错的图硬裁。

---

## 第 3 步：生成 ico（30 秒）

最省事：双击 `一键生成图标.bat`，把图拖进窗口 → 输入底部文字 → 回车。
产物在图片同目录的 `icon_out\` 里：`<名字>.ico` 和一堆核对用 PNG。

命令行等价写法：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\make_icon.ps1 `
  -Art "D:\art\editor.png" -Name "代码编辑器"
```

**必须检查 16 px**：打开 `icon_out\<名字>_16.png`，放大看还能不能认出「发色 + 脸」。
认不出就改两个数重跑：

- 脸偏左/偏右 → `-HeadX 0.55`（往右）或 `0.40`（往左）
- 脸偏上/偏下 → `-HeadY 0.50`（往下）或 `0.38`（往上）
- 脸太小 → `-FaceCrop 0.30`；脸太大 → `0.42`

一般 2–4 轮就稳，别一次调太多。

---

## 第 4 步：换图标（20 秒）

一条命令同时生成并替换桌面快捷方式（会先备份原图标）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\make_icon.ps1 `
  -Art "D:\art\editor.png" -Name "代码编辑器" `
  -Lnk "$env:USERPROFILE\Desktop\代码编辑器.lnk"
```

只想生成不替换，去掉 `-Lnk` 就行。替换后若桌面还是旧图，执行：

```powershell
& "$env:SystemRoot\System32\ie4uinit.exe" -show
```

系统项（此电脑 / 回收站 / 控制面板）不能用这条，走 `docs\03-system-icons.md`。

---

## 第 5 步（可选）：守住图标

软件更新会把快捷方式重写回默认图标，把这几个加进守卫清单：

```powershell
Copy-Item .\tools\icon_guard_config.example.json .\tools\icon_guard_config.json
notepad .\tools\icon_guard_config.json
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\icon_guard.ps1 -Once -Verbose
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install_icon_guard.ps1 -ConfigPath .\tools\icon_guard_config.json
```

## 卡住了看这里

| 现象 | 原因 | 解决 |
|---|---|---|
| `python 不是内部或外部命令` | 没装或没进 PATH | 重装 Python，勾 Add to PATH；或用 `py -3` 代替 `python` |
| `No module named PIL` | 依赖没装 | `pip install pillow numpy` |
| 16 px 一团糊 | 取景太远 / 对比太低 | 调 `-FaceCrop`、`-HeadY`；出图时让发色与背景拉开明度 |
| 图标四角有白边 | 源图不是正方形或带白底 | 重新出 1:1 图，或先抠成透明底 PNG |
| 底栏文字被裁 | 文字太长 | 用缩写（Photoshop→PS），或 `-Name ""` 不加字 |
| 换了图标没变化 | Explorer 缓存 | `ie4uinit.exe -show`，仍不行重启 explorer |
| 报“字符串缺少终止符” | 用记事本另存破坏了编码 | 脚本保持 UTF-8 with BOM，别用旧版记事本改 |
